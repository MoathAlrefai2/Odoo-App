HR Announcement Board

Keep your team informed with an internal notice board visible directly on employees' Odoo dashboards.

Key Features

Rich Text Announcements

Create beautiful announcements using Odoo's native HTML editor. Embed images, links, and text formatting.

Auto-Expiring Posts

Set expiry dates so outdated announcements automatically hide from the dashboard. Say goodbye to manual cleanup.

Priority & Pinning

Highlight critical updates! Pin important announcements to the top of the board and color-code by priority level.

Dedicated Employee Dashboard

Employees get a clean, read-only Kanban dashboard showing only active and published announcements. They can click any card to read the full details.

  • Pinned items stuck to the top
  • Color-coded borders based on priority
  • Securely restricted via Record Rules

Full Manager Control

HR Managers have full control over the announcement lifecycle:

  • Draft → Published → Expired workflow
  • Internal Chatter integration for collaboration
  • Set publish and expiry dates in advance
